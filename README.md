# RaceDay Management System

## System Description
The RaceDay System is a comprehensive web-based platform designed to streamline the organization, management, and participation in athletic racing events. It bridges the gap between event organizers who create and manage races and participants who register, track events, and view their official race results.

## System Roles
* **Organizer:** Has administrative privileges to create events, manage categories, oversee participant enrolments, and publish race results.
* **Participant:** A registered user who can browse upcoming events, enroll in race categories, manage their user profile, and review past performance results.
